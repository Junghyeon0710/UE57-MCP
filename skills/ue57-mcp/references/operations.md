# Operations

Use current schemas for exact names, argument capitalization, and object-reference types. Read MCP `isError` and nested engine error/return fields; a successful HTTP response alone does not establish successful asset modification.

Semantic Search is the full engine-derived plugin, with captioning/embedding endpoints configured in Editor Preferences. Missing endpoints require configuration; do not substitute filename search while claiming semantic results.

The 5.7 toolset may report unsupported 5.8-only properties or node types. Report those concrete limits, preserve the user's assets, and use supported operations only when they satisfy the requested outcome. Avoid silently replacing a requested native workflow with a smaller API wrapper.

For long operations, use returned results/state and logs. UE 5.7 does not provide the backport's SSE progress stream; lack of a stream is not proof of failure.
